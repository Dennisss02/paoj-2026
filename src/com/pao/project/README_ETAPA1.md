# Proiect - Programare Avansată pe Obiecte în Java

## Platformă Food Delivery

### a) Acțiunile posibile
- înregistrează un utilizator 
- înregistrează un restaurant 
- adaugă un produs în meniul unui restaurant
- elimină un produs din meniul unui restaurant
- modifică prețul unui produs din meniul unui restaurant
- listează produsele unui restaurant, sortate după preț 
- listează produsele unui restaurant, în functie de categorie 
- listează restaurantele, sortate după media prețurilor 
- initiază o comandă
- adaugă un articol la comandă
- elimină un articol din comandă 
- plasează o comandă 
- marchează o comandă ca finalizată
- anulează o comandă
- afisează istoricul comenzilor finalizate 
- listează comenzile unui utilizator

### b) Obiectele din domeniu
`Persoana`, `Client`, `Angajat`, `Sofer`, `Manager`, `Produs`, `ArticolMeniu`, `ArticolComanda`, `Restaurant`, `Comanda`, `AdresaLivrare`
